# ML Computer Vision MediaPipe Companion

A browser-based machine learning and computer vision prototype built with Google's MediaPipe Tasks Vision API. The application performs real-time hand gesture recognition, finger counting, face landmark tracking, and visible facial movement analysis directly from a webcam.

## Features

- Real-time webcam input
- Hand gesture recognition
- Finger counting
- Face landmark tracking
- Visible facial movement detection
- Live confidence scores
- Browser-based inference using MediaPipe

## Built With

- JavaScript
- HTML
- CSS
- MediaPipe Tasks Vision API

## Running the Project

1. Clone the repository.
2. Open the project in Visual Studio Code.
3. Launch with Live Server.
4. Allow webcam access.
5. Click **Start Camera**.

## Notes

This project uses Google's pre-trained MediaPipe models. No custom machine learning models are trained. Facial outputs represent visible facial movements only and should not be interpreted as emotional states. Make sure Live Sever extension is installed in VS code.
